# Weekwise typography

Plus Jakarta Sans by The Plus Jakarta Sans Project Authors (Tokotype).

Source: https://github.com/google/fonts/tree/main/ofl/plusjakartasans

The upstream variable TrueType font is converted to WOFF2 without subsetting or changing its glyphs, family metadata or weight range (200–800). Full SIL Open Font License 1.1 and copyright notice are included in `OFL.txt` and shipped with the client. The app serves this file itself and does not contact a font service.

WOFF2 SHA-256: `c680cf2e71e5a1faa5af9da5edf054509f984d33bfe417bfb7b2ae70891845f0`

Conversion: FontTools TTFont, set `flavor="woff2"`, save. The content-derived filename is immutable and cached in the offline shell. System fonts remain the fallback if loading fails.
