# Weekwise design system — incremental foundation

Plan introduces scoped tokens in `css/weekwise-plan.css`: surface, soft surface, text, muted text, line, accent and warning. Green branding is preserved; existing view styles are not bulk-replaced. Body `data-theme=dark` overrides the scoped palette, matching existing theme behavior.

## Components

- Page heading: 30px desktop / 26px mobile, restrained letter spacing; supporting text explains the workflow.
- Cards: 16px radius, 22px padding desktop / 16px mobile, visible one-pixel border.
- Forms/buttons: minimum 44px height; actual labels; flexible wrapping; checkbox labels with large clickable areas.
- Metrics: plain labels, numeric durations, distinguish estimates/capacity from actual work.
- Preview rows: checkbox, title, date/time and explanation; escaped task text.
- Warnings: readable amber surface and text, textual reasons rather than color alone.
- Status: polite live region. Selected application/errors are announced.
- Focus: visible 3px outline with offset. No drag-only action in Plan.

## Responsive layout

Five preference/metric columns on wide desktop, three below 1000px and two on phones. Date field spans the phone width. Days/buttons wrap and task explanations break safely; task-edit actions stack on mobile. Semantic fieldset groups weekday choices.

## Pending quality gates

Do not claim WCAG 2.2 AA certification. Complete contrast measurements, keyboard traversal, screen-reader review, dialog focus containment, text zoom and installed-PWA/mobile-keyboard testing. Screenshot artifacts are generated by browser CI at 1440, 820 and 390px; they require visual review. Full-app typography, icon and navigation consolidation remains Phase 2 work.
